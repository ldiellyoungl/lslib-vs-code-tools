## 📖 О расширении

**LSLib VS Code Tools** — это расширение для Visual Studio Code, которое интегрирует инструменты из [LSLib](https://github.com/Norbyte/LSLib) прямо в ваш редактор. Больше не нужно переключаться между окнами и консолью — распаковывайте моды, конвертируйте ресурсы и редактируйте файлы прямо в привычной среде разработки.

## ✨ Возможности

### 📦 Работа с PAK архивами

| Функция             | Описание                                         |
| ------------------- | ------------------------------------------------ |
| **Распаковка PAK**  | Извлечение `.pak` архива в папку с тем же именем |
| **Запаковка в PAK** | Создание `.pak` архива из папки одним кликом     |

### 🔄 Конвертация ресурсов

Поддержка всех основных форматов Larian Studios:

- **LSF ↔ LSX** — бинарный формат ↔ XML (удобно для редактирования)
- **LSF ↔ LSJ** — бинарный формат ↔ JSON
- **LSB ↔ LSX/LSJ** — скриптовые бинарные форматы

### 🌍 Конвертация локализации

- **LOCA ↔ XML** — конвертация файлов переводов в читабельный формат

### 🆔 Генерация UUID

Криптографически стойкая генерация UUID v4 прямо в редакторе:

- Вставка в позицию курсора
- Замена выделенного текста

### 🔢 Работа с версиями

- **Автоматическое декодирование** — при открытии `.lsx` файла рядом с `Version64` отображается читабельная версия (например, `1.0.0.0`)
- **Кодирование версии** — ввод версии в формате `Major.Minor.Revision.Build` и конвертация в `int64`
- **Умное определение** — при выделении числа `Version64` автоматически подставляется текущая версия

### 👁 Визуальные декорации

Автоматическое отображение декодированных версий прямо в редакторе:

```xml
<attribute id="Version64" type="int64" value="36028797018963968"/>  ← v1.0.0.0
```
