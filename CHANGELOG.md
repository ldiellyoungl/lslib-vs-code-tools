# Changelog

## [2.0.0] - 2026-10-21

Это масштабное обновление, которое знаменует собой полную переработку расширения.

### 🚀 Ключевые изменения

- **Полный рефакторинг и переход на TypeScript.** Вся кодовая база была переписана с нуля. Это дало строгую типизацию, избавило от множества скрытых багов и заложило фундамент для будущих фич.
- **Новая архитектура.** Логика разделена на независимые модули (парсинг, валидация, работа с файловой системой). Это сделало расширение более отзывчивым и безопасным.
- **Оптимизация производительности.** Переработаны механизмы чтения файлов и кэширования (например, при работе с локализациями). Расширение больше не блокирует интерфейс во время выполнения тяжелых операций.

### ✨ Новые возможности

- **Пакетная обработка файлов.** Добавлена поддержка массовой распаковки `.pak` файлов и пакетной конвертации ресурсов через `divine CLI`.
- **Улучшенная поддержка `meta.lsx`.**
  - Добавлен надежный парсер на базе `sax` для работы с XML-деревом.
  - Добавлен полноценный `HoverProvider` для подсказок по атрибутам, типам и нодам (будет дополняться).
  - Добавлен `DiagnosticProvider` для полноценной диагностики файла.
  - Внедрены визуальные маркеры (`InlayHints`) для декодирования и быстрого редактирования `Version64`, а также генерации нового `UUID`.
  - Появились быстрые действия (`CodeLens`) для копирования и вставки `ModuleShortDesc`.
- **Конфигурация расширения.** Теперь вы можете настроить `game`, `compressionMethod` и `logLevel` для `divine CLI` прямо в настройках расширения.

### 🐛 Исправления

- Исправлены ошибки позиционирования курсора и подсветки при работе с XML.
- Улучшена стабильность работы с путями файловой системы (поддержка различных структур папок модов).
- Устранены конфликты команд в контекстном меню и палитре команд.
